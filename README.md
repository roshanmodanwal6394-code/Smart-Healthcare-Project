# Smart Healthcare Analyzer

An interactive healthcare analytics dashboard developed
using Python, Streamlit, Pandas, Plotly and Apache Spark SQL.

## Features

- Healthcare KPI dashboard
- Patient record explorer and search
- CSV upload and download
- Department analytics
- Patient condition analysis
- Age group analysis
- Monthly admissions visualization
- Apache Spark SQL Lab
- Interactive charts and filters

## Requirements

- Python 3.10 or 3.11 recommended
- Java 17 recommended for PySpark 3.5.3
- pip

## Installation

Create a virtual environment:

    python -m venv .venv

Activate it on Windows PowerShell:

    .\.venv\Scripts\Activate.ps1

Install dependencies:

    pip install -r requirements.txt

Check Java:

    java -version

## Run

    streamlit run app.py

The application will open in your browser.

## Dataset

The project includes a small synthetic healthcare dataset.
Do not use identifiable real patient information.
